# GymFinder Canada 🇨🇦

## Application Description

**GymFinder Canada** is an Android mobile application designed to help users discover and explore gyms across different cities in Canada.

The application aims to make finding suitable fitness facilities easier by providing users with information about gyms, location-based discovery, and convenient features for managing their fitness preferences.

The app is being developed using **Kotlin** and **Jetpack Compose**, following modern Android development practices.
